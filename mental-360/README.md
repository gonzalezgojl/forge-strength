# MENTAL 360\n\nAplicación web progresiva (PWA) en español para iPhone. Incluye planificación de tres prioridades, hábitos, temporizador de concentración, diario mental, objetivos personales y estadísticas semanales.\n\n## Publicación\nLa aplicación vive en `/mental-360/` dentro del repositorio que ya tiene GitHub Pages habilitado. No modifica la aplicación FORGE que está en la raíz.\n\n## Privacidad y datos\nLos registros se guardan en `localStorage` del navegador/dispositivo. No se envían a un servidor. Usa **Datos → Exportar copia** para descargar un respaldo JSON. Borrar los datos del navegador puede eliminar los registros locales.\n\n## Instalar en iPhone\nAbre la URL publicada en Safari → Compartir → Añadir a pantalla de inicio.\n
